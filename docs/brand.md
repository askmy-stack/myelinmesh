# Brand and Naming

## Final name

**MyelinMesh**

## Meaning

Myelin is the biological insulation that helps neural signals travel efficiently and reliably. A mesh connects many independent nodes. The name represents a system that connects reliability evidence across tools, agents, software changes, simulations, physical systems, incidents, and recoveries.

## Positioning

> The reliability evidence mesh for AI systems.

Long description:

> MyelinMesh is an open-source evidence layer that connects changes, tests, traces, failures, diagnoses, recoveries, and human reviews into reusable reliability knowledge for AI and Physical AI systems.

## Voice

- Evidence-oriented
- Technically precise
- Cautious about causality
- Open and research-friendly
- Product-focused without certification claims

## Naming conventions

- Product: `MyelinMesh`
- Repository: `myelinmesh`
- Python package: `myelinmesh`
- CLI: `myelinmesh`
- Evidence record: `MER`
- Configuration directory: `.myelinmesh/`
- Environment prefix: `MYELINMESH_`

## Naming due diligence

An exact-name search did not identify an obvious GitHub, PyPI, or npm project using `MyelinMesh` at repository creation time. A separate open-source agent-learning project uses the shorter name `Myelin`; MyelinMesh must therefore consistently emphasize **reliability evidence and provenance**, not reusable workflow learning.
