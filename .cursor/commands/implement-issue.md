Implement the requested issue or task.

Follow `AGENTS.md`.

Before editing:

1. inspect the relevant code;
2. inspect related tests;
3. confirm acceptance criteria;
4. state the intended files to modify.

Implementation rules:

- make the smallest correct change;
- avoid unrelated refactors;
- preserve backward compatibility unless explicitly changing it;
- add regression tests for bug fixes when practical;
- add positive and negative tests for new behavior where appropriate;
- do not silently add dependencies;
- do not merge.

At completion report files changed, implementation summary, tests added or
changed, validation commands and results, remaining risks, and anything not verified.
